# potato_japanese
Rime日本語方案
##  📦 项目结构
```
potato_japanese/
├── potato_japanese.schema.yaml      # 主方案配置文件
├── potato_japanese.dict.yaml        # 总词典（汇总所有子词典）
├── jp_dicts/                        # 子词典目录
│   ├── ptt_kana                     # 假名
│   ├── ptt_waji                     # 和字（日语汉字）
│   ├── ptt_sentence                 # 常用句式
│   ├── ptt_part-1                   # 地理（山脉、河流、地区）
│   ├── ptt_part-2                   # 颜色（日本传统色）
│   ├── ptt_part-3                   # 人际关系
│   ├── ptt_part-4                   # 运动
│   ├── ptt_part-5                   # IT
│   ├── ptt_part-6                   # 名人（作家）
│   └── ptt_part-7                   # 姓氏
│   └── ptt_part-8                   # 时间
│   └── ptt_part-9                   # 地铁站点
│   └── ptt_part-10                  # 学校
```
